PURPOSE

Design how students interact with CareerGPS from

==================================================
PHASE 8.1
USER JOURNEY
==================================================

PRIMARY USER

Class 10 Student

GOAL

Help students understand available paths and
discover careers aligned with their interests.

--------------------------------------------------
STEP 1 - LANDING PAGE
--------------------------------------------------

Student opens CareerGPS

Message:

"Not sure what to do after 10th or 12th?
Let's explore your options."

Actions:

[ Start Journey ]
[ Explore Careers ]
[ Browse CareerMap ]

--------------------------------------------------
STEP 2 - STUDENT PROFILE
--------------------------------------------------

Collect:

- Current Class
- Stream (if selected)
- Age

--------------------------------------------------
STEP 3 - MODE SELECTION
--------------------------------------------------

Available Modes:

1. Explore Mode
2. Journey Mode
3. Discovery Mode

Recommended:
Journey Mode

--------------------------------------------------
STEP 4 - QUESTION FLOW
--------------------------------------------------

Student answers:

- Interest Questions
- Skill Questions
- Work Preference Questions
- Goal Questions
- Constraint Questions

--------------------------------------------------
STEP 5 - PROFILE GENERATION
--------------------------------------------------

CareerGPS generates:

- Interests
- Skills
- Traits

--------------------------------------------------
STEP 6 - RECOMMENDATIONS
--------------------------------------------------

Results shown as:

Strong Match
Good Match
Worth Exploring

--------------------------------------------------
STEP 7 - CAREER DETAILS
--------------------------------------------------

Student selects a career

Display:

- Description
- Required Skills
- Required Subjects
- Education Routes
- Reality Check

--------------------------------------------------
STEP 8 - CAREERMAP
--------------------------------------------------

CareerGPS generates:

Possible Routes

Example:

10th
↓
Science
↓
B.Tech
↓
Software Engineer

--------------------------------------------------
STEP 9 - SAVE PLAN
--------------------------------------------------

Options:

- Save CareerMap
- Download (Future)
- Share (Future)

--------------------------------------------------
STEP 10 - NEXT ACTIONS
--------------------------------------------------

Examples:

- Explore Science Stream
- Learn about JEE
- Compare Career Routes

PHASE 8.5
MOBILE-FIRST DESIGN
==================================================

WHY MOBILE FIRST?

Most students access websites using phones.

--------------------------------------------------
RULE 1
ONE QUESTION PER SCREEN
--------------------------------------------------

GOOD

Question

Option A
Option B
Option C

BAD

10 questions on one page

--------------------------------------------------
RULE 2
THUMB FRIENDLY DESIGN
--------------------------------------------------

Minimum button height:
48px

Large touch targets

--------------------------------------------------
RULE 3
SHORT QUESTIONS
--------------------------------------------------

Avoid:

"What type of professional environment
would you prefer?"

Use:

"Where would you like to work?"

--------------------------------------------------
RULE 4
