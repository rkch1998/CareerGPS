==================================================
CAREERGPS
PHASE 11.5
LOCAL DEVELOPMENT SETUP GUIDE
VERSION 1.0
==================================================

PURPOSE

Help any developer setup CareerGPS locally.

==================================================
REQUIREMENTS
==================================================

Java 17

Maven 3.9+

PostgreSQL 15+

Node.js 22+

Git

VS Code or IntelliJ

==================================================
STEP 1
CLONE REPOSITORIES
==================================================

git clone careergps-backend

git clone careergps-frontend

==================================================
STEP 2
DATABASE SETUP
==================================================

Create Database

careergps

Create User

careergps_user

Grant Permissions

==================================================
STEP 3
BACKEND SETUP
==================================================

Configure

application-local.yml

Run

mvn spring-boot:run

Verify

http://localhost:8080/api/v1/health

==================================================
STEP 4
FRONTEND SETUP
==================================================

Install

npm install

Run

npm run dev

Verify

http://localhost:5173

==================================================
STEP 5
CONNECT FRONTEND
==================================================

Backend

localhost:8080

Frontend

localhost:5173

==================================================
STEP 6
VERIFY MVP
==================================================

Questions Load

Assessment Works

Recommendations Return

CareerMap Displays

==================================================
COMMON ISSUES
==================================================

Port Conflict

Database Not Running

Incorrect Credentials

Node Version Mismatch

==================================================
SUCCESS CRITERIA
==================================================

✓ Backend Running

✓ Frontend Running

✓ Database Connected

✓ Health Endpoint Working
